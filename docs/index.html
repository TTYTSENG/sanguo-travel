資料範圍與來源 Public data coverage and provenance

發表人：凸肚男 · tzesmann@gmail.com。本目錄有34個城市入口、6,040筆原文或概述、2,830筆地名關聯、15筆文物或遺址及3,404個官方車站。

Sanguo Travel connects modern cities with public historical and fictional sources. Its catalog contains 34 cities, 6,040 original passages or chapter outlines, 2,830 candidate place relationships, 15 museum objects or sites and 3,404 official station names. These catalog counts are not a count of verified historical events. The historical book and the novel are clearly separated. Museum information was checked on October 4, 2026, and station information was compiled on October 5, 2026. Current opening hours, exhibitions and ticket availability must be verified with the official institution. This project is published by 凸肚男 and offers Chinese and English controls, an optional read-aloud service and a journal stored in your browser. No account is required. Original passages remain in Chinese. The public source pages provide selected excerpts, record IDs, source links and limitations so that readers can check the evidence before drawing a conclusion.

常見問題 Frequently asked questions

這些地名是否就是事件發生地 Is a place mention the event location

不是。地名可能是籍貫、引文或回顧，人物也是候選；請核對每筆原文及來源。 A place mention can be an origin, quotation or retrospective reference. People are candidates. Verify the original passage before asserting where an event happened.

英文版有完整古籍翻譯嗎 Are all source passages translated

英文版提供操作介面、城市說明與館藏介紹，正史與小說原文保留中文。 The English interface covers controls, city guidance and museum descriptions. Original historical and novel passages remain in Chinese; this is not a complete English translation.

能否查即時餘票 Does the app show live train availability

本網站產生12306官方查詢入口，不取得即時餘票、票價或代購。請在官方網站或APP確認站名、日期與席別。 The app builds official 12306 links. It does not retrieve live seats or fares, buy tickets or handle account credentials. Verify the station, date and seat class on the official service.

旅遊紀錄存在哪裏 Where is the journal stored

紀錄存在目前瀏覽器，請匯出JSON備份。WebMCP只查公開資料或帶入未儲存草稿；草稿需由您按儲存。 Journal records stay in the current browser. Export a JSON backup before clearing browser storage. Site tools query public sources or prepare an unsaved draft. The user must review and press Save; no tool returns existing journal entries.
